# ПЕРИМЕТР: Нулевая орбита — Alpha 0.9 (Android UI fix)

Оригинальная однопользовательская космическая стратегия для Android: шесть секторов станции, астероидная шахта, колонии и транспортные цепочки, космический флот, исследование и торговля. Движок **Godot 4.7.2 stable**, режим GL Compatibility, интерфейс для горизонтального экрана. В архиве — **исходный проект, не APK**.

## Новое в Alpha 0.9

Исправлена раскладка HUD на Android: счётчик циклов больше не переносится вертикальной колонкой, высота верхней строки ограничена, игровая карта занимает доступное место. Добавлена проверка HUD в `test_ui` и адаптация соотношения сторон экрана. Симуляция, сохранения и механика эскортов остались версии v8.

## Ранее добавлено в Alpha 0.8

**Сопровождение грузовых рейсов.** В разделе «ФРАКЦИИ» игрок отправляет товары в торговый рейс (понадобится свободный грузовоз). Затем в разделе «ФЛОТ» выбирает свободный корабль класса **«Эскорт»** и назначает его на конкретный активный торговый рейс. Назначение стоит **3 топлива**. До прибытия оба корабля недоступны для других заданий. Эскорт снижает вероятность перехвата на **20 процентных пунктов** (до минимума 0%), а при успешном налёте сам получает повреждения, защищая грузовоз. На карте галактики сопровождаемый рейс отмечен кольцом бирюзового цвета.

**Сохранения v8.** Состояние охраны, оставшееся время и занятость кораблей сохраняются. При загрузке файлов v7 отсутствующее поле сопровождающего корректно заменяется на `-1` (без эскорта). Проводится проверка ссылок между грузовым рейсом и кораблём. Автосохранение каждые 5 циклов, три ручных слота и резервные файлы сохранений сохранены.

## Уже реализованные механики

- **Станция:** 6 секторов 12×8, 12 типов зданий, население, производство, энергетика, корпус, мораль, улучшения до уровня 10.
- **Шахта:** геологоразведка, случайные залежи, шахтёры с задержкой перемещения, автоматическая разработка пластов и грузовой шаттл.
- **Колонии:** 13 видов объектов, дороги, локальные склады, заводские маршруты доставки и межпланетные конвои.
- **Галактика:** 8 систем и 13 путей, разведка, корабли трёх классов, пиратская опасность и независимые торговые рейсы других фракций.
- **Экономика:** исследования, биржа, дипломатические поставки, контракты, сюжетные события и кампании.
- **Сражения:** пошаговые приказы, повреждения кораблей, отступление и трофеи.

## Проверить проект на компьютере

1. Установить [Godot 4.7.2 stable](https://godotengine.org/download/archive/4.7.2-stable/).
2. Распаковать ZIP **с сохранением структуры папок**, импортировать `project.godot` в Godot Project Manager.
3. Для проверки в командной строке из корневой папки выполнить:

```bash
python3 tools/validate_static.py
python3 tools/verify_catalog.py
python3 tools/check_release.py
godot --headless --path . --import
for test in test_sim test_expansion test_ui test_03 test_04 test_05 test_06 test_07 test_08; do
  godot --headless --path . --script "res://tests/$test.gd" || exit 1
done
```

`test_08` проверяет назначение эскорта, расход топлива, предотвращение двойного использования корабля, снижение вероятности перехвата, освобождение кораблей по прибытии, целостность и загрузку v7 → v8.

## Получение Android APK через GitHub Actions

1. Создать **отдельный репозиторий** и загрузить туда *всё содержимое распакованного проекта*, включая скрытую папку `.github`.
2. Открыть **Actions → Perimeter Zero | Tests and Android APK → Run workflow**.
3. Workflow устанавливает Godot, экспортные шаблоны, Android SDK и Java, импортирует проект, запускает 9 тестовых сценариев и только затем экспортирует APK.
4. Если сборка успешна, скачать `PerimeterZero-Android-Alpha-0.8-debug` в **Artifacts**. Если нет — проверить `PerimeterZero-Alpha-0.8-failure-logs`.

Для обновления APK поверх предыдущей версии нужно использовать одну и ту же подпись. По умолчанию CI создаёт новый debug-ключ при каждом запуске. Можно сохранить постоянный ключ в секрете `PZ_DEBUG_KEYSTORE_BASE64`; приватный ключ **нельзя включать в репозиторий**.
