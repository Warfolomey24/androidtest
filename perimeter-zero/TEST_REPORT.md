# Alpha 0.8 — технический отчёт

## Проведено локально

- Распакован и изучен реальный исходный архив Alpha 0.7.
- Проверено, что CLI `godot` и `adb` не установлены; вызов `curl` к GitHub не проходит DNS-разрешение в контейнере.
- Обновлена модель торгового рейса: назначение `escort_index`, блокировка корабля на `cargo_eta`, снижение риска пиратов, раздельные повреждения, освобождение по прибытии.
- В `_valid_snapshot()` добавлена проверка `escort_index`: границы массива, класс корабля, отсутствие повторного назначения, совместимость таймера. В `load_game()` добавлена миграция v7 → v8.
- Реализованы кнопки сопровождения во вкладке «ФЛОТ», статус в «ФРАКЦИЯХ», кольцо охраны на карте галактики.
- Добавлен сценарий `tests/test_08.gd`; версии проекта, экспорта APK и контрольного скрипта согласованы с Alpha 0.8.

## Запустить отдельно

Локальные Python-проверки:

```bash
python3 tools/validate_static.py
python3 tools/verify_catalog.py
python3 tools/check_release.py
python3 -m compileall -q tools
```

GitHub Actions автоматически выполнит импорт в Godot и 9 игровых сценариев, включая тест нововведений v8. Ни один из этих девяти тестов **не был запущен движком в данной среде**. Сборка Android и запуск на телефоне **не подтверждены**.

Возможны ошибки GDScript или логики, которые статические Python-проверки не обнаруживают. Это следует считать блокирующим условием до первой проверенной сборки.
