# Умная Точка 0.3

Лёгкий рабочий стол для Redmi Note 9, Android 12 / MIUI 13. Kotlin и нативные Android Views. Без рекламы и доступа к интернету.

## Рабочий стол

Чёрно-белый интерфейс и монохромные значки. Логотип на основе знака «Умная Точка». Сверху отдельные иконки «Все приложения» и «Диспетчер». Часы, дата, до восьми избранных приложений, поиск, скрытие и восстановление приложений. Удержание значка открывает настройки.

Жесты внутри лаунчера: вверх — приложения, вниз — настройки, от левого края в списке — назад.

## Системные жесты

MIUI блокирует штатные полноэкранные жесты со сторонним лаунчером. Дополнительная служба «Жесты Умной Точки» включается пользователем в специальных возможностях. От бокового края — Назад; из нижней центральной зоны вверх — Домой; вверх с удержанием — Недавние.

Служба не получает содержимое окон, не читает текст экрана и не передаёт данные. Перед скрытием кнопок проверьте жесты. Перед отключением службы верните кнопочную навигацию. Не подтверждайте переход на штатный рабочий стол MIUI, если хотите сохранить этот лаунчер.

## Дополнительные приложения

- monitor: история использования за 24 часа, доступная ОЗУ, снимок процессов с ПК.
- phone: набор номера, контакты, журнал, экран разговора через Android Telecom.
- sms: чтение, приём и отправка текстовых SMS после выбора приложения по умолчанию.
- camera: предпросмотр, фото, переключение камер и вспышка при поддержке устройством.

Дополнительные приложения рассчитаны на Android 10+. Приложения звонков и SMS по умолчанию выбираются через системное окно. Существующие приложения связи сохраняются. SMS оплачиваются по тарифу оператора. MMS/RCS и видео пока не реализованы. Реальные звонки и обмен SMS требуют отдельного испытания с SIM-картой; проверка запуска не заменяет такие испытания.

## Диспетчер

История использования не является списком текущих процессов. Для неё требуется доступ к статистике использования. Нажатие на приложение открывает системные сведения о нём.

Список процессов — снимок ps с компьютера через USB, с отметкой времени. Обновление: scripts/refresh-processes.ps1. Скрипт не завершает процессы и не отправляет данные в GitHub. Без подключения к ПК снимок остаётся прежним. RSS не равен PSS и не показывает точный уникальный расход памяти приложением.

## Сборка и обновление

GitHub Actions: Build debug APK. Артефакт Merlin-Launcher-Lite-debug содержит пять APK в каталогах модулей. Java 17, Gradle 8.9, AGP 8.7.3, Kotlin 2.0.21, SDK 35. Gradle Wrapper не включён.

Команда сборки: gradle :app:assembleDebug :monitor:assembleDebug :phone:assembleDebug :sms:assembleDebug :camera:assembleDebug

CI сохраняет тестовый ключ подписи через GitHub Actions Cache для совместимых обновлений. Если кеш будет удалён, подпись может измениться; перед переустановкой сохраните настройки. Это debug-сборки; производственного ключа в репозитории нет.

Обновление: adb install -r с APK соответствующего модуля. Идентификатор лаунчера остаётся dev.merlin.launcher: переименование сохраняет настройки и службу жестов.

## Ограничения и возврат

Виджеты, папки и несколько рабочих столов пока не поддерживаются. Прирост скорости не заявляется без сопоставимых измерений. MIUI Home не отключать: он остаётся резервным. Для возврата выберите системный рабочий стол в настройках приложений по умолчанию и включите кнопочную навигацию перед отключением службы жестов.

Не публикуйте списки установленных приложений, снимки процессов, SMS, контакты и другие личные данные.
