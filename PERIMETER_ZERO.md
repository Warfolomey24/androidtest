# ПЕРИМЕТР: Нулевая орбита

Независимый проект Godot находится в каталоге [perimeter-zero](perimeter-zero/). Код Android-приложения в корне не изменён.

Сборка Alpha 0.8 выполняется через GitHub Actions, workflow `Perimeter Zero - Android APK (Alpha 0.8)`. APK появляется как артефакт `PerimeterZero-Android-Alpha-0.8-debug`, только если импорт, игровые тесты и экспорт успешны.
