# Проверка на Redmi Note 9 / MIUI 13

- [ ] Debug APK собран без ошибок.
- [ ] APK устанавливается через `adb install -r`.
- [ ] В списке системных приложений появился Merlin Launcher Lite.
- [ ] Встроенный `ROLE_HOME` / настройки MIUI позволяют назначить его основным.
- [ ] После нажатия Home показывается Merlin.
- [ ] В меню присутствуют все ожидаемые приложения (включая Google и сторонние).
- [ ] Избранное открывает Телефон, Сообщения, Камеру, Chrome.
- [ ] Поиск по русским и английским названиям работает.
- [ ] Долгое нажатие добавляет и убирает избранное, скрывает приложение.
- [ ] Скрытое приложение возвращается через меню.
- [ ] Back закрывает список приложений.
- [ ] После перезагрузки выбранный лаунчер сохраняется.
- [ ] Звонки, уведомления, камера, NFC и Wi-Fi работают как прежде.
- [ ] Трёхкнопочная навигация работает; системные жесты могут быть недоступны на MIUI.
- [ ] Возврат на MIUI Home через настройки телефона проверен.
- [ ] `dumpsys meminfo` и `gfxinfo` сняты до/после, сравнение повторено 3 раза.
