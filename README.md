# Merlin Launcher Lite 0.1

**Лёгкий альтернативный рабочий стол для Redmi Note 9 (merlinnfc), Android 12 / MIUI 13.**

Нативный Kotlin + Android Views, без Compose, AndroidX, фоновых служб, рекламы и доступа к интернету. Собирается как обычный APK, root и разблокировка загрузчика **не нужны**.

## Что уже есть

- Домашний экран: часы, дата, до 8 избранных приложений.
- Список приложений: сетка 4 колонки, сортировка по названиям, поиск.
- Свайп вверх с домашнего экрана открывает список; также есть кнопка.
- Удержание приложения: добавить/убрать из избранного, скрыть из списка, открыть сведения.
- Возможность вернуть скрытые приложения через меню `⋯`.
- Запрос назначения лаунчером по умолчанию (Android ROLE_HOME), переход в системные настройки как запасной путь.
- Без запросов разрешений, без интернета, без аналитики.

## Важные ограничения версии 0.1

- Не поддерживает Android-виджеты, пользовательские папки, изменение иконок, точки уведомлений, несколько рабочих столов и быстрые жесты системной навигации.
- MIUI 13 может отключать полноэкранные **системные** жесты при выборе стороннего лаунчера. Если такое произошло, включите 3-кнопочную навигацию: *Настройки → Рабочий стол → Системная навигация*. Свайп вверх **внутри самого лаунчера** останется доступен.
- Проверка на физическом Redmi Note 9 и компиляция в текущей среде ещё не выполнены. На первом этапе это **исходный проект**, не готовый APK.
- Замена лаунчера не исправит задержки, связанные с eMMC, нехваткой ОЗУ, перегревом или другими системными службами.

## Самый простой способ получить APK: GitHub Actions

1. Создайте пустой репозиторий GitHub (например `Merlin-Launcher-Lite`).
2. Загрузите **содержимое** этого архива в корень репозитория, включая `.github/workflows/build-apk.yml`.
3. Перейдите на GitHub: **Actions → Build debug APK → Run workflow**. Если workflow запустился при push, ручной запуск не нужен.
4. После успешного завершения откройте выполнение и скачайте артефакт **Merlin-Launcher-Lite-debug**.
5. Распакуйте `app-debug.apk` из скачанного ZIP.
6. На ПК с подключённым телефоном выполните одну команду:

   ```powershell
   C:\platform-tools\adb.exe install -r "C:\ПУТЬ\app-debug.apk"
   ```

   Или установите APK обычным способом с подтверждением на телефоне.

Сборка использует Gradle 8.9, Android Gradle Plugin 8.7.3, JDK 17, compileSdk 35 и Kotlin 2.0.21.

## Android Studio / Codex

- Откройте корень проекта в Android Studio с JDK 17 и установленным Android SDK Platform 35.
- Если студия требует Gradle Wrapper (он намеренно не включён, поскольку бинарный `gradle-wrapper.jar` здесь недоступен), воспользуйтесь Gradle 8.9 локально или сформируйте wrapper командой `gradle wrapper --gradle-version 8.9`.
- Собирайте `:app:assembleDebug`.
- Готовый APK: `app/build/outputs/apk/debug/app-debug.apk`.
- `AGENTS.md` содержит задания и правила для Codex.

## Как включить лаунчер

1. Откройте Merlin Launcher Lite в списке приложений.
2. Нажмите «Все приложения» → `⋯` → «Сделать основным лаунчером».
3. Подтвердите запрос Android либо выберите **Merlin Launcher Lite** в *Настройки → Приложения → Приложения по умолчанию → Рабочий стол* (путь MIUI может отличаться).
4. Удерживайте значки для добавления в избранное.

## Как вернуть штатный MIUI Home

Откройте настройки телефона: *Настройки → Приложения → Приложения по умолчанию → Рабочий стол* и выберите **Системный лаунчер / MIUI Home**.

**Не выполняйте `pm disable-user ... com.miui.home` и не удаляйте `com.miui.home`.** Стандартный лаунчер остаётся резервным и может участвовать в работе недавних приложений / жестовой навигации.

## Измерение до/после

Пока MIUI Home установлен по умолчанию, снимите показатели скриптом:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\measure-launcher.ps1 -Package com.miui.home
```

После перехода на Merlin Launcher:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\measure-launcher.ps1 -Package dev.merlin.launcher
```

Файлы появятся в `measurements/`. Сравнивайте память, плавность **при одинаковой нагрузке**, лучше после перезагрузки и нескольких минут работы. Само по себе число процессов не равно скорости.

## Исходники

- `app/src/main/java/dev/merlin/launcher/MainActivity.kt` — все экраны и логика.
- `app/src/main/AndroidManifest.xml` — стандартная роль `HOME` и видимость доступных для запуска приложений.
- `.github/workflows/build-apk.yml` — сборка debug APK.
- `scripts/measure-launcher.ps1` — диагностика, без изменений телефона.

Не отправляйте в GitHub файлы со списком ваших приложений и результаты личной диагностики, если они могут содержать чувствительную информацию.
